pls doc this: when opp closed won -> boomi picks up -> NS SO gets created?? or is it manual

if acct missing in NS it creates cust first. exch rate comes from NS daily job (ask fin team)

see comments 14–37 for edge cases… also check w/ QA before UAT!!

Opportunity to Sales Order (Salesforce → NetSuite)

Trigger: An opportunity is marked Closed Won in Salesforce.

  1. Boomi picks up the closed opportunity.
  2. If the account doesn't exist in NetSuite, Boomi creates the customer first.
  3. NetSuite creates the Sales Order, using the daily exchange rate.
  4. A credit evaluation runs. If it fails, the order is placed On Hold.
  5. After fulfillment, the delivery order syncs back to Salesforce.

Before UAT: Confirm edge cases with QA. See the linked test plan.
